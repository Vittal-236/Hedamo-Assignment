# Hedamo - Product Listing Walkthrough

This walkthrough demonstrates the key flows of the Hedamo Product Listing Interface, ensuring compliance with the "Producer Declared" standard.

<video src="hedamo_walkthrough_1767687740175.webp"></video>

## Flows Demonstrated
1.  **Registry Overview**: Scrolling through the full list of products.
2.  **Filtering**: Selecting "Published" to filter the list.
3.  **Detail Inspection**: Opening "Organic Cotton Bale - Grade A".
4.  **Compliance Check**: Highlighting the yellow warning banner that explicitly states the data is *not verified*.
